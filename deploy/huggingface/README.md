# KavachPay · live demo

A UPI payments assistant protected by **ShieldLayer**: a 3-layer zero-judge
security pipeline (deterministic funnel, quarantined intent extractor, and
symbolic RBAC/ABAC policy gate) paired with an application-level origin gate
that decides who may trigger each action.

Each visitor gets **4 free requests** on the hosted model. After that, watch the
**Recorded demos** (all 8 missions replayed, no tokens) or add your own Gemini key.

Source code and write-up: see the GitHub repository linked in the Space settings.
